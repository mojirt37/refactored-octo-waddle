# فروشگاه اینترنتی بامبرو

## توضیحات پروژه

فروشگاه اینترنتی **بامبرو** یک پروژه **WordPress + WooCommerce** برای فروش رنگ ساختمانی، پوشش‌ها، زیرسازی، عایق/محافظ، ابزار و محصولات مرتبط در بازار ایران است. این پروژه به صورت **Production-Ready**، تست‌شده، مستند و قابل استقرار طراحی شده است.

## ویژگی‌ها

- پشتیبانی کامل از **RTL** و زبان فارسی (fa-IR).
- طراحی حرفه‌ای برای مخاطبان ایرانی.
- محصولات متنوع در حوزه رنگ و ابزار ساختمانی.
- امکان مشاوره رنگ برای مشتریان.
- فیلترهای پیشرفته برای محصولات.

## ساختار پروژه

```
refactored-octo-waddle/
├── wp-content/
│   ├── themes/
│   │   └── bambroo/          # تم سفارشی بامبرو
│   └── plugins/              # پلاگین‌های سفارشی
├── README.md                 # مستندات اصلی پروژه
├── DECISIONS.md              # ثبت تصمیمات مهم
└── .gitignore               # فایل‌های نادیده گرفته شده
```

## نصب و راه‌اندازی

1. ریپازیتوری را کلون کنید:
   ```bash
   git clone https://github.com/mojirt37/refactored-octo-waddle.git
   ```
2. فایل‌های WordPress را در سرور خود آپلود کنید.
3. پایگاه داده را تنظیم و فایل `wp-config.php` را پیکربندی کنید.
4. تم `bambroo` را فعال کنید.
5. WooCommerce را نصب و پیکربندی کنید.
